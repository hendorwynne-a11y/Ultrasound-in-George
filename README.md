# Hendor's Diagnostics Website

This is a static website for Hendor's Diagnostics.

## Files required in GitHub root

Upload these files directly into the main repository page:

- index.html
- hero.png
- vercel.json
- README.md

Do not upload the ZIP file itself.
Do not place these files inside another folder.

## Vercel settings

When importing into Vercel:

- Framework Preset: Other
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: leave empty

## Deployment steps

1. Open your GitHub repository.
2. Delete the old files.
3. Upload index.html, hero.png, vercel.json, and README.md directly into the root.
4. Commit changes.
5. Open Vercel.
6. Go to the project.
7. Click Redeploy.
8. Choose Redeploy without build cache.
